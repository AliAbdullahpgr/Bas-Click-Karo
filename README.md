# Bas Click Karo

Static Next.js street playground. No backend, signup, database, or external asset requests.

## Run

~~~sh
npm install
npm run dev
~~~

Open http://localhost:3000. For a static build, run npm run build, then npm start. The exported site is in out/ and works on a static host. If an older preview is already using port 3000, rebuilding updates that static preview; refresh the page to load the new JavaScript.

## Interactions

- All four rickshaw destinations have real click targets and individual dialogue. A generated photographic rickshaw drives past with animated exhaust, then returns.
- Chai orders have different replies, a separate glass, steam and a sip animation. The fifth cup triggers the acidity joke.
- Uncle questions escalate into a boss fight. Rishta aunty, the driver, chai wala, cat and paan seller have short reply-based chats.
- Optional original music: Dhaba groove, Shaadi dhol, Raat ki chai. Synthesized dhol-inspired percussion and original flute-like phrases. Use Play desi radio, Next, volume, pause, or global mute. Music quiets during load shedding.
- Cat hops, chair drags (also arrow keys), bat starts cricket, pole triggers a five-second blackout, red button adds temporary chaos.
- The Pakistani quiz offers a local PNG result download and user-initiated sharing. The ninth click offers an invitation without interrupting a conversation.
- Smaller screens can scroll the street horizontally; the action dock stays accessible.

## Assets
